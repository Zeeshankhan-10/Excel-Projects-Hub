# 🛍️ Retail Store Sales Analysis (Excel Project)

## 📌 Overview
This project analyzes retail store transaction data to understand sales performance, customer purchasing behavior, and product trends. The goal is to generate actionable insights that can support business decisions and improve overall sales strategy.

---

- <a href="https://github.com/Zeeshankhan-10/Excel-Projects-Hub/blob/main/Excel%20Project%20-%204.xlsx"Dataset View </a> 
  
## 🎯 Objective
- Analyze sales performance across products and categories  
- Identify top-selling products and revenue contributors  
- Understand customer purchasing patterns  
- Evaluate sales trends over time  

---

## 🛠️ Tools Used
- Microsoft Excel  
- Data Cleaning  
- Pivot Tables  
- Data Analysis  
- Data Visualization (Charts & Dashboard)

---

## 📊 Dataset
The dataset includes transactional data such as:
- Order ID  
- Order Date  
- Customer ID / Segment  
- Product Category & Sub-Category  
- Product Name  
- Quantity  
- Sales / Revenue  
- Region / Location  

---

## 🔄 Process
- Cleaned and structured the dataset for analysis  
- Created pivot tables to summarize sales performance  
- Analyzed sales by category, region, and time period  
- Built visualizations to highlight trends and key metrics  

---

## 📈 Key Insights
- Certain product categories contributed the majority of revenue  
- Sales varied significantly across regions  
- A small group of products drove a large portion of total sales  
- Seasonal trends impacted sales performance  
- Customer segments showed different purchasing behaviors  

---

## ✅ Conclusion
This analysis provides valuable insights into product performance and customer behavior. These findings can help businesses optimize inventory, improve marketing strategies, and increase revenue through targeted decision-making.
