# 🎓 Student Performance Analysis (Excel Project)

## 📌 Overview
This project analyzes student performance data to understand the factors that influence academic success. The goal is to identify patterns in student behavior, study habits, and background that impact final scores and pass rates.

---

- <a href="https://github.com/Zeeshankhan-10/Excel-Projects-Hub/blob/main/Excel%20Project%20-%203.xlsx">Dataset View</a> 

## 🎯 Objective
- Analyze factors affecting student performance  
- Identify trends in study habits and attendance  
- Understand the impact of background variables on results  
- Support data-driven insights for improving student outcomes  

---

## 🛠️ Tools Used
- Microsoft Excel  
- Data Cleaning  
- Pivot Tables  
- Data Analysis  
- Data Visualization (Charts)

---

## 📊 Dataset
The dataset includes student-level data such as:
- Gender  
- Age  
- Study Hours per Week  
- Attendance Rate  
- Parental Education  
- Internet Access  
- Extracurricular Activities  
- Previous Scores  
- Final Scores  
- Pass/Fail Status  

---

## 🔄 Process
- Cleaned and reviewed dataset for consistency  
- Used pivot tables to analyze performance trends  
- Compared variables like study hours, attendance, and background  
- Identified relationships between inputs (study habits) and outcomes (final score)  

---

## 📈 Key Insights
- Students with higher study hours generally performed better  
- Attendance rate showed a strong correlation with final scores  
- Previous academic performance influenced final outcomes  
- Access to resources (like internet) impacted performance trends  
- Students engaged in extracurricular activities showed varied performance patterns  

---

## ✅ Conclusion
This analysis highlights the key factors influencing student performance. Understanding these variables can help educators and institutions develop strategies to improve student outcomes and support underperforming groups.
